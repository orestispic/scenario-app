Règles adaptatives

Les composants se recomposent lorsque la fenêtre rétrécit. On évite de créer une version visuelle différente pour chaque taille.

≥ 1440 pxspacious

Grille complète. Gaps 12–16 px. Panneaux latéraux à largeur préférée.

1100–1439 pxstandard

Réduire les gaps. Conserver les mêmes composants. Panneaux encore visibles.

800–1099 pxcompact

Réduire ou replier les sidebars. Menus et popovers inchangés. Grilles passent sur 1 colonne.

< 800 pxminimum

Priorité au contenu actif. Panneaux secondaires en overlay. Toolbar peut masquer les libellés non essentiels.

Les tokens, rayons, couleurs et composants restent identiques ; seuls disposition, largeur, visibilité secondaire et densité changent.
25

Animations principales

Animations courtes, fonctionnelles et cohérentes. Respecter prefers-reduced-motion.

Pas de spring exagéré · pas d’animation décorative · aucune animation ne doit ralentir l’écriture
